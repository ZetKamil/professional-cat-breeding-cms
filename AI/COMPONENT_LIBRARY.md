---

# Philosophy

Every UI element must be reusable.

Never duplicate markup.

Never duplicate Tailwind classes.

Every component should solve one problem.

All public pages should be assembled from reusable building blocks.

---

# Component Rules

Every component must have:

✓ single responsibility

✓ responsive

✓ accessible

✓ keyboard support

✓ reduced motion

✓ dark mode ready

✓ reusable

✓ documented
