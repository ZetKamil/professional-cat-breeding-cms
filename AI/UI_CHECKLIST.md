# UI_CHECKLIST.md

> Version: 1.0
> Purpose: Premium UI Quality Checklist
> Applies to: Every public page, every component, every redesign

---

# Philosophy

The frontend should feel like a luxury product.

Inspired by:

- Apple
- Aesop
- Airbnb
- Linear
- Tesla

The interface should disappear.

The animals should become the focus.

Never design to impress.

Design to build trust.

---

# 1. Layout

□ Mobile-first
□ Max content width 1280px
□ Comfortable reading width (65–75 characters)
□ Consistent horizontal padding
□ Consistent vertical rhythm
□ No cramped layouts
□ No unnecessary wrappers
□ Grid remains balanced
□ Layout scales from 320px to 2560px
□ No horizontal scrolling

---

# 2. Spacing

Whitespace creates quality.

Every page must feel breathable.

□ Section spacing 96–160px desktop
□ Section spacing 64–96px tablet
□ Section spacing 48–72px mobile

□ Card padding consistent

□ Equal spacing between related elements

□ No random margins

□ Use spacing scale only

Example

4

8

12

16

24

32

48

64

96

128

Never invent spacing values.

□ Large readable headings

□ No decorative fonts

□ Consistent font weights

# 23. Luxury Brand Check

Before shipping ask:

Does this feel premium?

Does it feel handcrafted?

Would Apple remove something here?

Can one element be removed?

Can spacing improve?

Can typography improve?

Can photography dominate more?

Can interaction become simpler?

If yes,

improve it.

# 24. Final Review

Before every commit

□ Design reviewed

□ Accessibility checked

□ Responsive checked

□ Performance checked

□ No duplicated UI

□ Components reused

□ Animations polished

□ Empty states implemented

□ Loading states implemented

□ Error states implemented

□ Documentation updated

□ TASKS updated

□ DEV_JOURNAL updated

Only then is the UI considered DONE.
