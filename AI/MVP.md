# MVP.md

## Goal

Deliver a complete, production-ready website and CMS for a professional cat breeder.

The MVP must be fully usable by the client and ready for deployment.

---

# Phase 1 — Foundation ✅

* Authentication
* Roles & Permissions
* Admin Dashboard
* AI Documentation
* Design System
* Base Layout
* Navigation
* Footer
* Homepage Structure

---

# Phase 2 — Animal Domain

## Backend

* Animal Model
* Animal CRUD
* Animal Categories (optional if needed)
* Animal Gallery
* Featured Animals
* Status Management
* Publishing
* SEO Fields

## Frontend

* Animal Listing
* Animal Detail
* Available Kittens
* Breeding Cats
* Queens
* Search
* Filters

---

# Phase 6 — SEO

---

# Phase 7 — CMS

The breeder must be able to manage:

* Animals
* Blog Posts
* Categories
* Images
* Homepage Content
* Contact Information
* Testimonials
* SEO

without developer assistance.

---

# Phase 8 — Quality

Before MVP is complete:

* Responsive
* Accessible (WCAG AA)
* Lighthouse >95
* SEO optimized
* Production ready
* No placeholder content
* No debug code
* No unfinished features

---

# Out of Scope (Post-MVP)

These features belong to future releases and must not delay MVP completion:

* Shop
* Shopping Cart
* Payments
* Reservations
* Customer Accounts
* Newsletter
* CRM
* Analytics
* Breeding Calendar
* Pedigree Generator
* Medical Records
* Mobile App
* Multi-language
* Public API

These features are defined in ROADMAP.md and will be implemented after MVP is delivered.
